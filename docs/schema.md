# Схема БД

15 таблиц + 3 представления. Все суммы — `BIGINT`, целые сумы.

## Люди и доступ

| Таблица | Назначение |
|---|---|
| `staff` | сотрудники; телефон = логин, `role` = права, `archived_at` = мягкое удаление |
| `app_settings` | одна строка: таймауты замка, режим переделки, лимит заявок |
| `audit_log` | кто, кого, когда, что изменил |
| `bot_sessions` | шаг диалога в боте (Edge Functions без состояния) |

## CRM

`clients` (госорганы) → `client_contacts` → `measurements` (мерки на конкретного человека).

## Заказы

`orders` → `order_items` → `tasks` (операция × изделие × исполнитель).

Пайплайн заказа: `new → measuring → fitting → production → qc → ready → delivered`.
Статусы задачи: `assigned → in_progress → done → accepted | rework`.

Переходы статусов задачи проверяет триггер `validate_task_transition`:
швея двигает только свои и только вперёд, приёмку делает менеджер.

## Зарплата

```
payroll_accruals  (начислено: piece / bonus / penalty / fixed)
payroll_payments  (выплачено: cash / card / transfer)
v_staff_balance   = сумма первого − сумма второго
```

`penalty` пишется отрицательной суммой — вся арифметика остаётся одним `sum()`.
Начисление создаётся триггером при переходе задачи в `accepted`.
При возврате в `rework` и `rework_forfeits_full = true` начисление удаляется.

Выплата триггером создаёт расход в `transactions` категории «Зарплата».

## Материалы и закуп

`supply_requests` → при `status = 'purchased'` триггер создаёт расход
в `transactions` («Материалы») и пополняет `materials.stock_qty`.

`v_supply_board` схлопывает одинаковые позиции от разных швей в одну строку.

## Финансы

`transactions` (`income` / `expense`) — единственный источник правды по деньгам.
Зарплата и закуп попадают сюда автоматически.

`v_order_profit`: выручка по позициям − материалы по заказу − труд по заказу.

RPC для отчётов: `public.finance_summary(from, to)`, `public.finance_daily(from, to)`.

## RLS — кто что видит

| | швея | менеджер | админ |
|---|---|---|---|
| свои задачи | ✅ | ✅ | ✅ |
| все задачи | — | ✅ | ✅ |
| заказы, мерки, заказчики | чтение | ✅ | ✅ |
| свои начисления и выплаты | ✅ | ✅ | ✅ |
| чужая зарплата | — | — | ✅ + PIN |
| `transactions` | — | — | ✅ + PIN |
| сотрудники | только себя | список | ✅ полное |

«+ PIN» = claim `fin_exp` в JWT, живой на момент запроса.
